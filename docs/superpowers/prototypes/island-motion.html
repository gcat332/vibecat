Layout & motion spec

The aura is an event

Light blooms out of the island's silhouette in the new state's colour and leaves nothing behind. A glow that stayed lit would be a second status indicator competing with the cat; a glow that only fires on change is punctuation. It traces the shape, so it can only exist outside the cutout, and it follows the panel down when the drawer opens.

Badges move too

Each badge is its own small animation, never a static glyph: four squares swelling in turn around a ring while work happens, a star twinkling when a run lands, a bang pulsing when an answer is wanted, a cross shuddering on failure, and z's drifting off a sleeping cat.

Marks carry their own state

With several agents at once each mark is tinted by its own status, so shape still says which agent and colour still says how it is doing — without a second dot per agent crowding the flank.

Pixel art, modern motion

The artwork is a 12×10 sprite with a dark outline, a lit top and a white sparkle in each eye — genuinely drawn on a grid. What moves it is not: easing curves, springs and soft pulses, the same vocabulary as the rest of the interface. Only the blink is instant, because a blink is.

The cat is the status

It sleeps when idle, trots while running, sits up with a ! when an agent needs you, squints happily on success and takes X eyes when something fails. Pose first, colour second, words never.

Chiptune, synthesised

Alerts are pulse and triangle oscillators with hard attacks and short decays — no audio files to ship. A rising two-note call when an agent needs you, a major arpeggio on success, falling minor thirds on a saw when something breaks.

The worst state wins

The island takes the most urgent session, not the most common: needs you > failed > running > idle. Waiting outranks failing because a waiting agent is idling on you right now, while a failed one has already stopped. This holds in the session list too — the view changes, the state does not.

The notch is a hole

The black shape may span the cutout, because the cutout is black too. Content may not. Everything sits left or right of 186pt.

Silence at rest

A resting island shows a mark and the cat, and nothing else. Hovering widens the flanks and reveals the name and elapsed time; only a click makes it verbose.

Choices stack

Answers run top to bottom, one per row, so a label like Allow all pnpm commands in ~/dev/api for this session stays readable instead of being truncated.

One click or many

A number badge means the click is the answer. A checkbox means it is not — those questions grow a Send button and a running tally, so a half-made selection can never be committed by reflex.

Session anatomy

Three lines, most urgent first: the project and its state, what the agent is doing right now beside where and how it runs, then the last thing you asked it.
